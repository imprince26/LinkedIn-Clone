## Overview

LinkedIn Clone is a modern web application built with the MERN stack that delivers a professional networking experience. Users can create detailed professional profiles, establish connections, share content with their network, and stay updated through a notification system. The platform features a sleek dark-themed UI with responsive design optimized for all devices.

---

## Key Features

### Authentication & Security
- Secure user registration and login with form validation
- JWT-based authentication with HTTP-only cookie sessions
- Password encryption using Bcrypt.js
- Protected routes and persistent login state

### Profile Management
- Comprehensive user profiles with profile picture and banner image uploads
- Editable sections: About, Headline, Location
- Experience management with company, title, and date range
- Education history with school and field of study
- Skills listing and management

### Connection System
- Send, accept, and reject connection requests
- View and manage existing connections
- Remove connections from network
- Smart user suggestions excluding existing connections
- Connection status tracking (pending, connected, not connected)

### Posts & Feed
- Create posts with text content
- Image and video upload support (up to 50MB with auto-compression)
- Like and unlike posts
- Comment on posts with nested comment display
- Delete own posts and comments
- Chronological feed displaying all posts

### Notifications
- Notification system for:
  - Post likes
  - Post comments
  - Accepted connection requests
- Mark notifications as read
- Delete individual notifications
- Notification badge and listing page

### User Interface
- Modern dark-themed design
- Fully responsive layout (mobile, tablet, desktop)
- Lazy-loaded pages for optimized performance
- Toast notifications for user feedback
- Intuitive navigation with sidebar
